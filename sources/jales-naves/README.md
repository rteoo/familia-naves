## Source policy

The user designated Jales's Blog on Editora Naves as the primary editorial source for this project. That priority does not turn every reported date into a verified civil record. A reported family claim, a document described by Jales, our arithmetic and a correction supplied in conversation remain distinct. The Araçatuba/Blogger site was not collected or used to settle conflicts in these files.

This collection contains a complete catalogue of the 683 published posts returned by category 12, automatic name/date discovery fields extracted from their fetched bodies, and focused factual summaries. It is not a verbatim mirror or an exhaustive semantic summary of every article. Ordinary news and institutional articles are retained in the catalogue so scope is explicit. The collection does not alter the existing website files.
